installation steps for Watcher lite 1.1

To install Watcher lite 1.1 please follow the steps below:

1. Run a "sudo apt update".
2. Install python on your computer if not already installed.
3. Install python 3 PIP tools "sudo apt install python3-pip".
4. Install scapy, requests, colorama, and rich using "pip install scapy requests colorama rich".
5. Update bad_ips.txt to include any IP addresses you believe to be malicious.
5. Clone the gitHub.  Run watcher lite using superuser prividges "sudo python3 watcherlite1_1.py"
